Por que uma hospedagem feita para WordPress faz diferença

O WordPress roda mais de 40% dos sites do mundo, mas é exigente: cada página aberta consulta o banco de dados e executa dezenas de plugins. Em uma hospedagem genérica, isso vira lentidão no painel, carrinho travando e nota baixa no Google.

Na EreHost o WordPress roda sobre o LiteSpeed Web Server com o plugin LiteSpeed Cache, que entrega páginas prontas direto da memória. Nos planos Cloud, o Redis guarda as consultas ao banco e reduz o tempo de resposta em até 3 vezes.

O WordPress é gerenciado: instalação em um clique, atualizações acompanhadas e Elementor PRO incluso para você montar páginas sem pagar licença à parte.

O Elementor PRO está mesmo incluso?

Sim. Os planos de Hospedagem e Cloud incluem o Elementor PRO, o construtor visual mais usado no WordPress, sem custo de licença à parte.

O que é WordPress gerenciado?

É o WordPress instalado e acompanhado pela EreHost: instalação em um clique, servidor ajustado para ele, cache configurado e suporte que entende de temas e plugins.

O que o LiteSpeed Cache faz pelo meu site?

Ele guarda versões prontas das páginas e entrega direto do servidor, sem processar PHP e banco a cada visita. O resultado é um site que abre muito mais rápido, inclusive em dias de pico.

Quais planos têm Redis?

O Redis, que faz cache de objetos do banco de dados, está nos planos Cloud: 64 MB no Cloud Starter, 128 MB no Cloud Premium e 256 MB no Cloud Enterprise.

A hospedagem serve para WooCommerce?

Serve. Todos os planos têm otimização para WooCommerce: básica no Starter e no Plus, padrão no Premium e avançada nos planos Cloud, que são os mais indicados para lojas com bastante movimento.

Vocês migram meu WordPress de outra hospedagem?

Sim. A partir do plano Plus, a migração é gratuita: nossa equipe copia arquivos, banco de dados e e-mails e deixa tudo funcionando, normalmente em menos de 24 horas.

Qual versão do PHP vocês usam?

PHP 8.5, sempre atualizado. Se um plugin antigo precisar de outra versão, dá para trocar pelo painel.

Tenho backup do meu WordPress?

Sim. Os planos de Hospedagem têm backups automáticos e os planos Cloud têm backups diários, com restauração pelo suporte.
